The notebook defaults to `photo_001.jpg` for “Show what you see!”. Change
`IMAGE_NAME` and rerun the selection and encoding cells to use another photo.
Each question sends the selected photo once; API usage is billed separately.

You can add JPG/JPEG, PNG or WEBP photos. Remove personal information first
and clear notebook outputs before sharing. Original user-supplied photos remain
in the ignored `user_supplied/` folder; the rights above apply only to the three
selected course photos.
