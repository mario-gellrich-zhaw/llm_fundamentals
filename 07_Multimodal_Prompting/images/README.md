# Course photos

The three photos are AI-generated images bundled locally for course use.

| File | Scene |
|---|---|
| `photo_001.jpg` | Horses in a meadow |
| `photo_002.jpg` | Dog with sunglasses in a bicycle basket |
| `photo_003.jpg` | Busy London street intersection |

The notebook defaults to `photo_001.jpg` (horses). Change
`IMAGE_NAME` and rerun the selection and encoding cells to use another photo.
Each question sends the selected photo once; API usage is billed separately.

You can add JPG/JPEG, PNG or WEBP photos. Remove personal information first
and clear notebook outputs before sharing.
